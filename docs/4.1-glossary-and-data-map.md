# 4.1. Словарь и карта данных

[Оглавление](README.md)

## Термины

| Термин | Смысл |
|---|---|
| Posting | Проведение бизнес-операции с учётными последствиями |
| Release | Подготовка документа к дальнейшей обработке |
| Receipt / Shipment | Получение / отгрузка |
| Invoice | Фактурирование, не оплата |
| Credit Memo | Корректирующий кредитовый документ |
| Ledger Entry | Учётная запись |
| Application | Применение/связь записей; смысл зависит от подсистемы |
| Expected Cost | Предварительная стоимость нефактурированного количества |
| Actual Cost | Фактурированная стоимость с корректировками |
| Cost Adjustment | Передача изменений стоимости по её цепочке |
| WIP | Незавершённое производство |
| Flushing | Автоматическая регистрация производственного потребления/выпуска по настройке |
| Reservation | Закрепление предложения за спросом |
| Tracking | Идентификация партии или единицы |
| Dimension | Аналитический признак |
| Symbol | Описание объекта/API для разработки |
| Runtime | Целевая версия возможностей AL |
| PTE | Расширение для конкретного tenant |

## Основные таблицы

| Таблица | Типичный ключ/связь | Что доказывает |
|---|---|---|
| Item | No. | Настройку товара |
| Sales Header | Document Type + No. | Заголовок активного документа |
| Sales Line | Document Type + Document No. + Line No. | Его строку |
| Purchase Header / Line | Аналогичная составная идентификация | Закупочный процесс |
| Item Ledger Entry | Entry No. | Количественное движение |
| Value Entry | Entry No.; Item Ledger Entry No. для товарной связи | Стоимостный эффект |
| Item Application Entry | Inbound / Outbound Item Entry No. | Связь приходов и расходов |
| G/L - Item Ledger Relation | Ссылки на Value Entry и General Ledger Entry | Бухгалтерское отражение стоимости |
| Warehouse Entry | Location, Bin, Item и регистрационные ссылки | Движение по ячейкам |
| Reservation Entry | Источник, знак и связи предложения/спроса | Активное назначение |
| Dimension Set Entry | Dimension Set ID + Dimension Code | Состав аналитического набора |

Состав и точные ключи проверяйте в symbols целевой версии. Это карта для чтения, а не инструкция прямой записи в стандартные учётные таблицы.

## Какой путь выбрать

**Почему изменился запас:** Item → Item Ledger Entries → исходный документ и Item Application.

**Почему изменилась себестоимость:** нужный Item Ledger Entry → все Value Entries → adjustments и источник стоимости.

**Почему не сходится бухгалтерия:** Value Entries → cost posted → G/L - Item Ledger Relation → General Ledger Entries, с одинаковой датой отчёта.

**Где находится партия:** Item/Location/Lot → Warehouse Entries и Bin Content → открытые складские задания и reservations.

**Кто должен деньги:** Customer/Vendor Ledger Entries → Detailed Ledger Entries и применения, а не только Item Ledger Entries.

## Чего не обещают связи

Одна строка документа может создать несколько товарных записей; одна товарная запись — несколько стоимостных; одна стоимостная операция — несколько бухгалтерских строк. Общий Document No. помогает поиску, но не является универсальным foreign key.

Item Ledger Entry не хранит полную историю bins. Reservation Entry не заменяет историю проведённых движений. Unit Cost из карточки не заменяет стоимость исторического расхода. Dimension Set ID — ссылка на набор, а не расшифровка одной аналитики.
